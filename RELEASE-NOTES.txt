Mega Man 2 (NES) Static Recomp 1.2.3
19 November 2026

ROM compatibility

- Fixed rejection of clean USA game data when an otherwise compatible NES
  header differs from the original reference file.
- Accepts the verified 256 KiB USA payload in compatible iNES and NES 2.0
  containers or as a headerless dump. Select a .nes or .bin file.
- Preserves save states across these formats and with the reference
  ROM accepted by earlier versions.
- Updated RecompLauncher fingerprints and included ROM-REQUIREMENTS.txt
  in the portable package.

Headless verification

- Booted the Windows launcher into gameplay with legacy iNES, NES 2.0
  and headerless ROMs. Also verified .BIN auto-discovery.
- Checked alternate NES 2.0 size encoding, save and restore in both
  directions across formats, and rejection of altered data, invalid
  cartridge layouts, trailing data and truncated files.
- The local regression suite passed the eight Robot Master stage and
  visual oracles, as well as the audio, snapshot and controller checks.

Windows 10 and 11 x64

Extract the Windows ZIP and run Launcher.exe. See ROM-REQUIREMENTS.txt
for the supported USA game payload and troubleshooting information.
