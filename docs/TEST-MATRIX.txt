1. Strict MSVC /W4 /WX build.
2. MMC1, generated seed, direct-core and snapshot self-tests.
3. Runtime-hook and shared headed/headless frame-path checks.
4. APU timer/mixer/resampler/IRQ self-test.

Exact-ROM gates:
1. ROM identity and 100,000-instruction smoke.

   display buffer, collision-safe names and checked file writes.
3. Four-checkpoint graphics/audio/state oracle.
4. All eight Robot Master stage load and visual oracles.
5. Exact APU PCM identities.
6. Multipart Metal Man route and snapshot continuity.

Release gates:
1. Portable Launcher.exe starts without third-party DLLs.
2. Controller settings expose Keyboard, Gamepad and combined input, with the
   bundled mapping database available beside Launcher.exe and no-device fallback.
   The single player has keyboard bindings and one gamepad slot; controller two
   remains idle at the static-core boundary.
3. Dialogs support Tab and Shift+Tab navigation, F1 opens the Welcome window,
   audio volume uses a 0-100 selector and applies immediately, and settings are
   flushed to the single SimCity-style settings.ini file when saved. General,
   display, audio, input, bindings and first-run Welcome state share that file.
4. Escape closes every frontend subwindow. Browse starts in the portable Rom
   folder, then persists the directory of a successfully selected external ROM.
5. Release contains no ROM and no pre-created empty output folders.
6. Source archive contains no binaries, media, caches or nested archives.
7. Both ZIP files pass CRC, duplicate-name and SHA-256 checks.
